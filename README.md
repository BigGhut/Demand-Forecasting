# Прогнозирование спроса (Demand Forecasting)

Мы успешно реализовали пет-проект Demand Forecasting с гибридной архитектурой Prophet + CatBoost для предсказания временных рядов со сложной сезонностью на данных Kaggle Store Sales.

## Архитектура и реализованный пайплайн

Проект построен с использованием строгого типизирования (PEP 484), валидацией конфигов через Pydantic и фреймворка Darts для обработки временных рядов.

### 1. Data Layer (src/data/)
- DataLoader: Парсинг и загрузка train, stores, oil, holidays, и transactions с кэшированием в .parquet.
- DataPreprocessor: Очистка данных, заполнение пропущенных дат нулевыми продажами, интерполяция/forward-fill цен на нефть.
- Localized Holidays: Интеллектуальный маппинг праздников. Праздники сопоставляются с географическими метаданными конкретного магазина (город city, штат state). Локальный праздник в одном городе размечается как обычный рабочий день для магазинов в других городах. Обрабатываются перенесенные праздники (transferred==True).

### 2. Feature Engineering Pipeline (src/features/)
Реализован мощный двухэтапный пайплайн признаков для избежания утечки данных (Data Leakage):
- Calendar Features: День недели, месяц, квартал, бинарные флаги выходных/праздников/выдачи ЗП.
- Payday Continuous Distance: Расчет непрерывного расстояния в днях до/после выплаты зарплаты (days_since_last_payday, days_until_next_payday) для тонкого моделирования динамики покупательной активности.
- Lag Features: Лаги [1, 7, 14, 28]. Встроен механизм защиты: минимальный лаг не может быть меньше горизонта прогноза (горизонт 28 дней).
- Rolling & Expanding Windows: Скользящее среднее и стандартное отклонение с окнами [7, 14, 28] для улавливания локальных трендов, а также расширяющееся окно для глобальной статистики.
- Dynamic Promo Features: Комплексная группа признаков для акций (onpromotion):
  - onpromotion_lead_1 (эффект ожидания акции завтра).
  - onpromotion_lag_1 (остаточный эффект от вчерашней акции).
  - onpromotion_rolling_sum_7 (плотность промо-активностей за неделю).
  - Скользящие максимумы и экспоненциальные средние (EMA) для окон [3, 7, 14].

### 3. Model Architecture (src/models/)
- Prophet (Trend & Seasonality): Моделирование годовой и недельной сезонности с мультипликативной формой.
- CatBoost (Residuals): Улавливание сложных нелинейных зависимостей (промо-акции, цены на нефть) на остатках (residuals) от Prophet. CatBoost обучен с использованием функции потерь RMSEWithUncertainty на GPU для оценки доверительных интервалов.
- Autoregressive Residual Lags: Устранение ошибки накопления (recursive forecasting error). Вместо Contiguous Lags (lags=28), модель явно использует исторические остатки Prophet за прошлые периоды (lags=[28, 35, 42, 56]) — ровно 4, 5, 6 и 8 недель назад. Это гарантирует надежность прогноза без расхождений.
- HybridPipeline: Оркестрация: Fit Prophet -> Извлечение остатков -> Fit CatBoost на остатках -> Синтез финального прогноза.

### 4. Target Transformations (src/transforms/)
- TargetTransformer: Поддержка обратимых преобразований (Difference, Log, Box-Cox) для стабилизации дисперсии и трендов с гарантированным round-trip тестом на точность инверсии.
- Log1p & expm1 Workflow: Используется в Streamlit как более стабильная альтернатива Box-Cox при наличии большого количества нулевых значений продаж в рядах данных.

### 5. Business Metrics & Visualization (src/evaluation/, src/visualization/)
- Метрики: Внедрены бизнес-показатели, такие как WAPE, MAPE, R2, Bias (PBIAS), Tracking Signal, CV (Coefficient of Variation), Direction Accuracy и Peak Capture Rate.
- Графики (Plotly): Реализована интерактивная декомпозиция предсказаний на тренд и остатки (decomposition_plots.py) и оценка доверительных интервалов (evaluation_plots.py).

### 6. ABC Segmentation & Routing (src/models/routing.py)
- ABCSegmenter: Сегментация временных рядов на классы A, B и C на основе правила Парето (по объему продаж).
- ForecastRouter: Динамическая маршрутизация прогноза. Для высокоприоритетных и стабильных товаров (Классы A и B) используется тяжеловесная гибридная модель (Prophet + CatBoost). Для товаров с редким или низким спросом (Класс C) Prophet пропускается, и используется быстрый CatBoostResidualModel напрямую. Это радикально экономит CPU без потери точности.

### 7. Hyperparameter Tuning (tune_hyperparams.py)
- Настроен фреймворк автоматического подбора гиперпараметров с использованием Optuna.
- Оптимизируются параметры: changepoint_prior_scale (Prophet), learning_rate и depth (CatBoost), а также выбор архитектуры авторегрессионных лагов.
- Встроена система штрафов (Penalty) за выход Tracking Signal за пределы [-4, 4], гарантирующая несмещенность прогнозов.

### 8. Asymmetric Inventory Optimization (app/main.py)
- Реализована динамическая маршрутизация квантиля прогноза в зависимости от специфики категории:
  - PRODUCE (Свежие продукты): Прогноз извлекается по квантилю P40 (минимизация overstock / списаний скоропорта, так как стоимость утилизации превышает упущенную прибыль).
  - GROCERY I (Бакалея): Прогноз строится по квантилю P75 (максимизация доступности товара на полке, минимизация out-of-stock).
  - Базовый сценарий: Медиана P50.

## Проверка работоспособности (Тесты)
- Написан End-to-End тест пайплайна (run_pipeline.py) и интерактивный дашборд app/main.py.
- Пайплайн автоматически отслеживает утечки данных (Data Leakage) и безопасно обрабатывает генерацию фичей (лаги и окна) через кастомный обработчик NaNs.
